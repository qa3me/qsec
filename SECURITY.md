# Security policy

[فارسی](#فارسی)

Send vulnerability reports privately to [contact@qa3.me](mailto:contact@qa3.me). Include the affected Qsec version, the WordPress and PHP versions, the impact, and steps to reproduce the issue on a test site. Redact passwords, tokens, and private site or user data from any examples.

Use [GitHub Issues](https://github.com/qa3me/qsec/issues) for public questions and ordinary bugs.

## فارسی
